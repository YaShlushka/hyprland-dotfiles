Утилита для поиска аккаунта с определенным юзернеймом в соцсетях и сайтах.
Использование:
`sherlock YaShlushka` - поиск аккаунта с именем YaShlushka
`sherlock --site github YaShlushka` - поиск пользователя YaShlushka на гитхабе
`sherlock --output file.txt YaShlushka` - сохранить результаты поиска в файл
